# 복사해서 쓰는 프롬프트

창립자가 Claude와 Gemini 사이를 오갈 때 그대로 복사해 붙여 넣는 프롬프트 모음.
`T-___` 부분만 바꾸면 된다.

---

## 0. Antigravity 처음 한 번 설정

```text
나는 개발을 모른다. 기술 용어 없이 한 단계씩 안내해 줘.
1) https://github.com/jeondusan-cloud/quant 저장소를 내 컴퓨터에 내려받아(clone) 그 폴더를 작업 공간으로 열어 줘.
2) GitHub 로그인이 필요하면 내가 어느 화면에서 무엇을 눌러야 하는지 알려 줘.
3) 준비가 끝나면 AGENTS.md를 읽고, 네가 이 저장소에서 어떤 규칙으로 일하는지 세 줄로 요약해 줘.
```

## 1. 세션 시작 (Claude, Gemini 공통)

```text
AGENTS.md를 읽고, ai/handoffs/에서 가장 최근 파일 하나만 읽어.
그다음 ai/TASKS.md의 T-___ 작업을 시작해.
작업에 필요한 파일만 읽고, 끝나면 AGENTS.md 5장 형식으로 인수인계 파일을 만들어.
```

## 2. 다음 할 일을 AI가 고르게 할 때

```text
AGENTS.md와 최근 인수인계 파일 하나를 읽고,
ai/TASKS.md에서 너에게 맞는 todo 작업 중 지금 가장 중요한 것 하나를 골라 이유와 함께 제안해. 시작은 내가 승인한 뒤에 해.
```

## 3. 교차 리뷰 요청 (만든 AI가 아닌 쪽에)

```text
AGENTS.md 7장 체크리스트로 T-___ 작업을 리뷰해 줘.
브랜치: ___ / 인수인계 파일: ai/handoffs/___
diff와 인수인계 파일 위주로 보고, 결과를 ai/reviews/T-___.md에 남겨.
결론은 "통과 / 수정 요청 / 사람 판단 필요" 중 하나로.
```

## 4. 리뷰 반영 (원래 만든 AI에게)

```text
ai/reviews/T-___.md의 수정 요청을 반영해 줘.
반영하지 않는 항목이 있으면 이유를 같은 파일 아래에 적어.
```

## 5. 세션 마무리 (사용량이 곧 끝날 것 같을 때)

```text
지금까지 한 일을 커밋하고, AGENTS.md 5장 형식으로 인수인계 파일을 만들어.
다른 AI가 이어받을 수 있도록 "남은 일"을 구체적으로 적어.
```

## 6. 큰 작업 쪼개기 (주로 Claude에게)

```text
T-___ 작업을 Gemini가 구현할 수 있는 작은 작업들로 쪼개서 ai/TASKS.md에 추가해 줘.
작업마다 수락 기준을 확인 가능한 형태로 적고, 하나는 반나절 안에 끝날 크기로.
```

## 7. 결정이 필요할 때

```text
이 선택지들을 ai/DECISIONS.md에 "제안" 상태로 정리해 줘.
각 선택지의 장단점과 너의 추천, 그리고 내가 판단할 때 볼 기준을 적어.
```
