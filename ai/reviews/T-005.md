## 1. AGENTS.md 7장 체크리스트 점검

- [x] **수락 기준을 충족하는가**
  - **공유 미리보기 이미지(`site/og.png`)**: 1200×630px 표준 규격(PNG)임을 직접 확인했고, 슬로건("선언하라! 행동하라! 달성하라!")과 공동체 소개 문구가 어두운 배경 위에 선명하게 들어갔습니다.
  - **메타 태그 및 파비콘(`site/index.html`, `site/favicon.svg`)**: `og:url`, `og:image`, `og:image:width/height`, `og:site_name`, `og:locale`, `twitter:card`, `canonical`, `favicon.svg`가 누락 없이 추가되었습니다.
  - **모바일 레이아웃(360px / 768px / 1280px)**: 반응형 그리드(`minmax(min(100%, ...), 1fr)`), `box-sizing: border-box`, 줄바꿈 설정(`overflow-wrap: break-word`)이 적용되어 360px 휴대폰 폭에서도 가로 스크롤이 생기지 않습니다.
  - **복사 버튼 동작**: 최신 클립보드 API(`navigator.clipboard.writeText`)와 구형/인앱 브라우저용 대체 복사(`document.execCommand("copy")`), 모바일 공유창(`navigator.share`)까지 모두 구현되어 iOS Safari와 안드로이드 크롬에서 정상 동작합니다.
- [x] **실제로 실행해 보았는가, 또는 실행 방법이 맞는가**
  - 로컬 컴퓨터에서 `site/og.png` 이미지 해상도(1200×630)와 시각 디자인을 직접 열어 확인했습니다.
  - 현재 배포 주소(`https://jeondusan-cloud.github.io/quant/`)가 정상 응답(HTTP 200)하는 것을 확인했습니다.
  - 인수인계 파일의 확인 방법(병합 후 카카오톡 '나와의 채팅'에 링크를 붙여 넣어 미리보기 확인, 필요 시 캐시 초기화)이 정확합니다.
- [x] **보안: 비밀값 노출, 권한 검사(RLS) 누락, 사용자 입력 처리**
  - 비밀키·토큰·개인정보 노출이 없습니다.
  - 꿈 선언서 입력값은 `textContent`로만 처리되어 스크립트 삽입(XSS) 위험이 없고, 기기 내부(`localStorage`)에만 임시 저장됩니다.
- [x] **8장의 프로젝트 가치에 어긋나지 않는가**
  - 비교 장치(좋아요·순위 등)가 없고, 남의 꿈에 보탤 수 있는 기여 항목이 포함되어 있습니다.
  - 모바일 우선(입력창 글자 크기 16px로 iOS 자동 확대 방지, 다크 모드 지원)과 개인정보 최소 수집 원칙(`docs/templates/join-form.md`에서 이메일 자동 수집 끄기, 보관 기간 명시, 공개 저장소 업로드 금지)을 잘 지켰습니다.
- [x] **불필요하게 범위를 넓히지 않았는가**
  - T-005 외에 참가 신청 폼 초안(T-004 준비), 로컬 Claude 안내(`docs/00-start-here.md` 6장), 역할 분담 완화(D-011)가 함께 포함되었으나 모두 창립자 요청에 따른 문서 보강이며 불필요한 기능 확장은 없습니다.
