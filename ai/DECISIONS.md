### D-007 슬로건: "선언하라! 행동하라! 달성하라!"

- 상태: 확정 · 날짜: 2026-10-22 · 결정: 창립자
- 결정: 대표 슬로건은 "선언하라! 행동하라! 달성하라!". "비웃지 않는다. 묻는다. 어떻게?"는 공동체 문화(규칙 1)로 유지한다.
- 반영: 세 단어를 공동체의 세 단계(꿈 선언 → 어떻게의 밤·원정대 → 90일 보고)와 일치시켰다. "달성"은 90일 끝까지 가서 결과를 공개하는 것으로 정의했다 (`docs/03-community-design.md` 6장). 목표 미달 보고도 달성으로 인정해야 성적 압박이 되지 않는다.

### D-008 저장소 공개 + GitHub Pages 배포

- 상태: 확정 · 날짜: 2026-10-22 · 제안: claude (창립자 질문 "공개로 바꾸면 되나?"에 대한 답) · 확정: 창립자가 공개 전환, 사이트 동작 확인
- 결정: 저장소를 공개하고 GitHub Pages로 `site/`를 자동 배포한다.
- 이유: 무료이고 추가 가입이 필요 없다. 선언문·전략을 공개하는 것은 "선언하라"와 맞고, 함께할 사람이 우리를 알아볼 수 있다.
- 조건: 다른 사람의 개인정보와 비공개 꿈 선언서는 저장소에 올리지 않는다.
- 확정 조건: 창립자가 T-010에서 공개로 전환하면 확정

### D-010 개발 관련 판단은 AI에게 위임

- 상태: 확정 · 날짜: 2026-10-22 · 결정: 창립자 ("나 개발 관련 모른다. 너가 알아서 처리하도록")
- 결정: 기술 선택과 실행은 AI가 추천안을 정해 처리한다. 사람에게는 쉬운 말로 결과와 눌러야 할 버튼만 안내한다. 돈, 외부 공개, 개인정보, 되돌리기 어려운 작업은 여전히 사람에게 묻는다.

### D-011 역할 분담 완화: 사용량이 남은 쪽이 맡는다

- 상태: 폐기 (D-012로 대체) · 날짜: 2026-10-22 · 결정: 창립자 ("클로드 자체도 사용량이 턱없이 부족한 건 아니어서 클로드로도 많이 작업할 거야")
- 결정: Claude도 구현을 직접 한다. 강점에 따른 기본 분담은 유지하되, 사용량이 남은 쪽이 맡는다. 자기가 만든 것은 다른 AI가 리뷰한다는 원칙은 그대로다.
- 덧붙임: 클라우드 세션은 플랜 사용량보다 클라우드 세션 크레딧을 먼저 쓴다. 크레딧 만료(2026-11-05) 전에는 클라우드 작업을 우선한다.
- 반영: `AGENTS.md` 2장, `CLAUDE.md`, `README.md`, `docs/00-start-here.md` 2장·6장
