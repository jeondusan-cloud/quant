# 창립자 사용 설명서 (개발 몰라도 됩니다)

창립자가 할 일은 세 가지뿐이다. **말하기, 결정하기, 초록 버튼 누르기.**
코드, 배포, 파일 정리는 Antigravity(Gemini)가 한다. 막히면 에이전트에게 "무엇이 잘못됐는지 확인하고 고쳐 줘"라고 말하면 된다. (Claude는 창립자가 따로 부를 때만 쓰는 선택 사항이다.)

---

## 1. 처음 한 번 설정 (5분)

GitHub 웹사이트(github.com)에서 이 저장소(`jeondusan-cloud/quant`)를 열고 순서대로 누른다.
화면 문구는 영어다. 아래 따옴표 안의 글자를 찾아 누르면 된다.

### ① 저장소 공개로 바꾸기

1. 저장소 위쪽 메뉴의 **"Settings"** (톱니바퀴)
2. 왼쪽 메뉴 **"General"** → 페이지 맨 아래 빨간 상자 **"Danger Zone"**
3. **"Change visibility"** → **"Change to public"** → 안내에 따라 확인

공개하면 누구나 이 저장소의 문서를 볼 수 있다. 선언문과 전략을 공개하는 것은 "선언하라"와도 맞다.
단, **다른 사람의 개인정보(연락처, 비공개 꿈 선언서 등)는 절대 저장소에 올리지 않는다.**

### ② 기본 브랜치를 main으로 바꾸기

"브랜치"는 작업본이다. `main`이 정식본이고, AI는 작업본에서 일한 뒤 정식본에 합친다.

1. **"Settings"** → **"General"** → **"Default branch"** 칸
2. 오른쪽의 화살표 두 개 모양 버튼(⇄) → **main** 선택 → **"Update"** → 확인

### ③ 웹사이트 켜기

1. **"Settings"** → 왼쪽 메뉴 **"Pages"**
2. **"Build and deployment"** 아래 **"Source"** 를 **"GitHub Actions"** 로 선택
3. 위쪽 메뉴 **"Actions"** → 왼쪽 **"사이트 배포"** → 오른쪽 **"Run workflow"** → 초록 **"Run workflow"**
4. 1~2분 뒤 초록 체크가 뜨면 완료. 주소: **https://jeondusan-cloud.github.io/quant/**

이후에는 `site/` 폴더가 바뀌어 `main`에 합쳐질 때마다 웹사이트가 자동으로 갱신된다.
(이름이 정해져서 저장소 이름을 바꾸면 주소도 바뀐다. 그때는 AI에게 맡기면 된다.)

## 2. Gemini(Antigravity)에게 일 시키기 (주 작업자)

1. Antigravity를 열고 에이전트 창에 [`ai/PROMPTS.md`](../ai/PROMPTS.md)의 **0번 프롬프트**(처음 한 번 설정)를 붙여 넣는다. 저장소를 `C:\quant`에 내려받고 GitHub 로그인하는 과정을 에이전트가 한 단계씩 안내한다.
   - **중요**: 저장소 폴더는 `C:\quant` 같은 짧은 경로에 두고, OneDrive와 연결된 '문서' 폴더나 `scratch` 폴더는 피한다.
2. 그다음부터는 **1번 프롬프트**로 작업을 시킨다. 그냥 하고 싶은 말을 편하게 해도 규칙(`AGENTS.md`)에 맞게 정리한다.
3. 작업이 끝나면 **새 에이전트 창(새 대화)**을 열어 **3번 프롬프트**로 교차 리뷰를 시킨다 (만든 대화와 다른 새 대화에서 검토).

## 3. Claude에게 일 시키기 (선택 사항, 필요할 때만)

평소에는 Gemini 혼자 모든 일을 처리하며, 창립자가 Claude를 따로 부르고 싶을 때만 쓴다.
**클라우드 세션 크레딧이 남아 있는 동안은 클라우드를 먼저 쓴다.** 크레딧을 다 쓰거나 만료되면 로컬과 클라우드 중 편한 쪽을 쓴다. → 6장

1. 로컬: Claude 데스크톱 앱의 **Code** 탭에서 이 저장소 폴더(`C:\quant`)를 연다 (6장). 클라우드: **claude.ai/code** 에서 저장소 `jeondusan-cloud/quant`를 골라 새 세션을 연다.
2. [`ai/PROMPTS.md`](../ai/PROMPTS.md)의 1번 프롬프트를 붙여 넣고 `T-___`에 작업 번호를 적는다.

## 4. 초록 버튼: 작업 합치기 (Pull Request 병합)

AI가 작업을 끝내면 "Pull Request(PR)"라는 합치기 요청이 생긴다.

1. 저장소 위쪽 메뉴 **"Pull requests"** → 요청 하나를 연다.
2. 새 에이전트 창(또는 다른 AI)의 리뷰가 "통과"인지 확인한다 (PR 댓글 또는 `ai/reviews/` 파일).
3. 초록 **"Merge pull request"** → **"Confirm merge"**

PR이 없고 브랜치만 있다는 안내를 받으면: 저장소 첫 화면에 뜨는 노란 띠의 초록 **"Compare & pull request"** → **"Create pull request"** 를 누르면 PR이 생긴다.

## 5. 하지 말아야 할 것

- 비밀번호, API 키, 다른 사람의 연락처를 채팅이나 저장소에 붙여 넣지 않는다.
- Settings의 모르는 버튼(특히 "Danger Zone")을 누르기 전에 AI에게 먼저 묻는다.
- AI가 돈이 드는 서비스 가입을 권하면 바로 하지 말고 이유를 다시 물어본다.

## 6. 내 컴퓨터(로컬)에서 Claude 쓰기 (선택 사항)

클라우드 세션은 Anthropic의 컴퓨터를 빌려 쓰는 것이고, 로컬은 내 컴퓨터에서 돌리는 것이다.

**무엇이 줄어드나** (claude.ai의 설정 → 사용량 화면에서 확인)

| 어디서 쓰나 | 무엇이 줄어드나 |
| --- | --- |
| 클라우드 세션 (claude.ai/code, 앱의 Cloud) | **클라우드 세션 크레딧**이 먼저 줄어든다. 크레딧을 다 쓰거나 만료되면 플랜 사용량이 줄어든다 |
| 로컬 (데스크톱 앱의 Local, 터미널) | **플랜 사용량**("현재 세션", "이번 주")이 줄어든다 |

그래서 크레딧에 만료일이 있으면 그 전까지는 클라우드를 먼저 쓰는 것이 이득이다. 크레딧이 끝난 뒤나 컴퓨터 안의 파일을 직접 다뤄야 할 때 로컬을 쓴다.

### 준비물 (처음 한 번)

1. **이 저장소 폴더**: Antigravity에서 `ai/PROMPTS.md`의 0번 프롬프트를 이미 했다면 내 컴퓨터의 `C:\quant`에 폴더가 있다. 저장소 폴더는 `C:\quant` 같은 짧은 경로에 두고, OneDrive와 연결된 '문서' 폴더나 `scratch` 폴더는 피한다.
2. **Windows라면 Git 설치**: git-scm.com/downloads/win → 내려받아 설치 (모든 질문에 기본값으로 "Next"). Mac은 필요 없다.

### 방법 A. 데스크톱 앱 (추천, 명령어 입력 없음)

1. **claude.com/download** 에서 Claude 데스크톱 앱을 설치하고, Pro 계정으로 로그인한다.
2. 왼쪽 위 **"Code"** 탭을 누른다.
3. 입력창 아래 줄의 첫 번째 버튼(환경 선택)을 눌러 **"Local"** 아래 맨 위 항목을 고른다.
4. 그 옆의 폴더 버튼 → **"Open folder…"** → 1번에서 기억해 둔 저장소 폴더(`C:\quant`)를 고른다.
5. 입력창에 `ai/PROMPTS.md`의 1번 프롬프트를 붙여 넣는다. 이 저장소의 규칙 파일(`CLAUDE.md`)은 자동으로 읽힌다.
6. 입력창 아래의 권한 모드는 처음에는 **"Manual"**(바꾸기 전에 매번 물어봄)로 두고, 익숙해지면 **"Accept edits"** 로 바꾼다.

### 방법 B. 터미널 (데스크톱 앱이 안 될 때)

1. 터미널을 연다. Mac: "터미널" 앱 / Windows: 시작 메뉴에서 "PowerShell"
2. 아래 한 줄을 붙여 넣고 Enter를 누른다. 아무것도 안 보여도 잠시 기다린다.
   - Mac: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
3. 터미널을 닫았다가 다시 열고 `claude --version` 을 입력해 숫자가 나오면 설치 완료
4. `cd C:\quant` 를 입력하고 Enter (또는 `cd ` 뒤에 저장소 폴더를 끌어다 놓고 Enter)
5. `claude` 를 입력하면 브라우저가 열린다. Pro 계정으로 로그인하면 시작된다.

### 로컬에서 지킬 것

- **같은 폴더에서 여러 작업 창을 동시에 돌리지 않는다.** 한쪽이 작업을 끝내고 "푸시까지 했다"고 말한 뒤에 다른 쪽을 시작한다. 동시에 고치면 서로의 작업을 덮어쓸 수 있다.
- 작업을 시작할 때마다 "먼저 GitHub의 최신 내용을 받아 와(pull)"라고 말한다. 1번 프롬프트에 이미 들어 있다.
- PR을 열지 못하면, 저장소 첫 화면의 초록 **"Compare & pull request"** 버튼을 누른다 (4장).
- 컴퓨터를 끄면 로컬 작업도 멈춘다. 오래 걸리는 일은 끝날 때까지 켜 둔다.
